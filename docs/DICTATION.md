# 紧凑界面与全局快捷听写

本次改动保留现有 Swift + Qwen 推理、HTTP API、模型与服务配置。主窗口默认和最小内容尺寸为 **560 × 440 pt**，设置窗口独立显示。

## 使用方式

1. 打开“设置 → 听写”，分别操作麦克风、辅助功能和输入监控授权。启动与快捷键路径只检查权限；快捷键触发时不会弹出授权对话框。
2. 将光标放在需要输入的文本框，单独按住右 Option。短于 150 ms 的按压忽略；达到阈值后开始录音，底部浮层显示波形与计时。
3. 松开后识别；录音最长 59 秒，达到上限自动提交一次。保持按键不会再次开始录音。Escape 取消录音或识别。
4. 目标保持有效且全部修饰键已松开时，发送一次普通 Cmd+V，遵循原选区的替换行为。不发送 Return，不自动发送消息。

设置页可改为“⌃／⌥／⌘ + 一个按键”的组合键，或恢复右 Option；系统已注册的快捷键与常用编辑组合会被拒绝。菜单栏可暂停听写。关闭主窗口不退出应用，听写仍可工作；退出应用后停止监听、取消任务并清理临时录音。

## 界面

- 顶部是“语音转文字／文字转语音”、引擎状态与设置入口。
- 中间是原生 `NSTextView` 文本区。支持长文本内部滚动、选择、撤销和输入法组合，不显示横向或纵向滚动条。
- 底部保留录音／生成、音频操作和固定状态区。较长错误通过详情面板查看。
- TTS 的表达指令与流式播放位于语音选项面板；音色、语言、重播和 WAV 保存仍可直接操作。
- 首次迁移紧凑界面时重置旧窗口尺寸，此后保存用户调整后的窗口大小。
- 设置为“听写／服务／通用与更新”三个分页；界面读取系统减少透明度与减少动态效果偏好。

## 目标与剪贴板保护

按键开始时记录前台应用 PID、焦点控件和可读取的选区／文本。应用切换、焦点通知、可用的选区及内容通知、键鼠交互和定期检查共同保护目标。一旦发现变化，本次会话永久停止自动输入；切回原位置也只保留识别结果。

每次识别返回带会话 UUID 的成功、取消或失败结果。自动输入仅消费当前全局听写会话的成功结果；手动录音和文件导入仅更新工作台预览。空结果、密码框、不可编辑控件、权限不足或目标无效均不自动粘贴。

粘贴前保存所有剪贴板条目及每个可读取格式的数据。无法完整保存时停止自动输入。写入临时文字时附带本次所有权标识，并在发出一次 Cmd+V 后等待至少 500 ms；即使这期间取消，也先保留目标应用读取的时间。仅在所有权标识与变更次数仍匹配时恢复原内容，不覆盖用户中途复制的新内容。退出时同步尝试恢复仍属于本次操作的剪贴板。

目标文本可读取时核对替换结果；无法确认时显示“粘贴已发出，请检查输入位置”，保留复制入口，不自动重试。一次粘贴已经发出后，取消无法撤销目标应用已经收到的文字。

浮层是非激活面板，不主动打开主窗口或抢占输入焦点。睡眠、锁屏、会话失活、监听失效和退出取消当前录音／识别并清理临时文件。麦克风授权仍在等待时，取消会使授权回复过期，不会在稍后授权完成后意外开始录音。

更新等待覆盖快捷键待启动、录音、识别、文本输出和剪贴板恢复，随后沿用现有服务请求排空协议。

## 真实设备验收

2026-11-06 验证时当前 macOS 桌面处于锁屏状态，无法完成真实键盘、麦克风和目标应用交互。以下项目仍需在解锁会话中使用安装后的候选 App 验收：

- TextEdit、Safari 输入框、VS Code／Electron 编辑器中的右 Option、真实中英录音与数字识别、选区替换、无重复输入、无自动发送。
- 识别期间切换应用、同应用内换输入框、改变选区后切回，均保留结果并停止自动输入。
- 用户中途复制、目标不支持读取文本、密码框、权限撤销、睡眠／锁屏／解锁和关闭主窗口后的行为。
- 系统“始终显示滚动条”、浅色／深色、减少透明度和减少动态效果下的完整窗口、工具栏、弹出面板与焦点导航。
- 真实麦克风 59 秒上限、扬声器连续播放、文件导入和 WAV 保存面板，以及更新安装前的真实排空体验。

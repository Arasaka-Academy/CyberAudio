# CyberAudio 0.4.2（9）

修复快捷键录入停在“等待按键…”以及听写按下后缺少反馈的问题。

- “修改…”弹窗在焦点移动后仍能接收组合键和右 Option；保留系统快捷键检查、Escape 取消及窗口隔离。
- 键盘状态恢复同时检查会话和 HID 状态；未观察到硬件按下时，不再用空的 HID 状态过早取消有效的会话按键。
- 按下听写快捷键立即显示“准备听写”浮层，按住满 150 ms 才开启麦克风；短按松开立即关闭，浮层保持原输入焦点。
- 推理引擎未就绪或其他音频正在处理中时，显示原因。
- 修复 Swift 6.3 发布工具链对快捷键匹配器初始化的兼容问题。0.4.1 未发布安装资产，改由本版本提供修复。

继续使用 Swift＋MLX Swift／Metal 及现有模型、配置和 API。使用方式见 [快捷听写说明](../DICTATION.md)。

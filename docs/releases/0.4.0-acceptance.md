# CyberAudio 0.4.0 发布与本机验收（2026-11-06）

版本 **0.4.0（7）** 已合入并推送 main，发布提交为 `b71a31f65517343a2366cef29b329d8b813702ee`，功能提交为 `615c419`。正式包已在本机安装，真实 Qwen 模型自动回归通过；真人录音和物理按键听写按用户安排稍后验收。

[Release](https://github.com/Arasaka-Academy/CyberAudio/releases/tag/v0.4.0) 与 [发布工作流](https://github.com/Arasaka-Academy/CyberAudio/actions/runs/42144219945) 已完成。签名发布资产、部署 Pages 稳定清单两个 CI 作业均为 success。新版提供紧凑 STT／TTS 工作台、按住右 Option 的全局听写，以及焦点与剪贴板保护，使用方法见 [发布说明](0.4.0.md) 和 [快捷听写说明](../DICTATION.md)。

运行时继续使用 **Swift＋MLX Swift／Metal**、Qwen3-ASR 1.7B 8-bit 和 Qwen3-TTS 1.7B CustomVoice 8-bit，App 不附带 Python 运行时。本次没有切换 Core ML／ANE，没有测量能耗或 ANE 使用情况。

## 正式安装包的真实模型回归

使用 `/Applications/CyberAudio.app` 内的正式工具和服务，在独立测试根运行完整回归，2026-11-06 02:44:34–02:45:46 UTC 完成，报告 `status=passed`。

| 检查 | 结果 |
| --- | --- |
| 23 个固定模型文件及两个 tokenizer | 全部通过 |
| 沙箱禁止出网 | ASR／TTS 可离线运行 |
| 认证与单实例所有权 | 通过 |
| 中文／英文 × WAV、WebM、MP3、M4A、FLAC、OGG、AIFF、AAC | 16 个识别请求通过 |
| 两条固定中英文合成语料 | 识别返回有效文本，含测试数字 |
| 9 个音色 | 均生成 24 kHz、单声道、PCM16 WAV |
| 完整 PCM 流 | 8 包，122,880 B，首包约 169 ms |
| 三轮断连取消与恢复 | 约 35.6–38.0 ms 排空，后续请求均返回 200 |
| stdin EOF | 服务清理通过，约 399.5 ms |
| App 推理中收到 TERM／KILL | 子进程消失、端口关闭、可重启；分别约 341.5／74.1 ms |

本轮识别输入来自 macOS `say` 的 Tingting／Samantha 合成语音，**不是 FLEURS 或真人语料**。这证明实际模型、格式解码和接口路径可用，不构成总体准确率、实体识别质量或自然语音表现评测。

隔离实例启动记录：文件校验 4,632.29 ms、模型加载 2,725.56 ms、预热 10,540.75 ms；Metal active 5,578,423,720 B、Metal peak 6,437,814,276 B、进程 peak RSS 4,917,182,464 B。这些是该次运行的不同统计口径，不能相加，也不是与 Python／Core ML 的性能对比。

初次隔离测试使用模型目录符号链接，在 macOS 27 上被 `FileManager.contentsOfDirectory(at:)` 报为 `Not a directory`。独立 Metal／ASR／TTS 推理和目录枚举复现将问题定位到测试路径；改用 APFS clone 的实体目录后，同一正式包和同一组模型哈希完整通过。默认安装配置使用实体模型目录，也通过后续验证。正式 App、产品源代码与签名没有因此修改。

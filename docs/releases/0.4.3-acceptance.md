## 验证结果

本地完整 `make check`、版本递增检查、App 构建及严格嵌套签名检查通过。远端完整回归、正式包构建与资产上传、Pages 更新源部署全部成功。

六个正式资产已通过 GitHub Release asset API 下载，长度、SHA-256 与发布清单一致。公开 Pages 清单与已签名的发布清单逐字节一致，版本为 0.4.3、build 为 10。清单及 ZIP 的 Sparkle EdDSA 签名验证通过。没有将 asset API 下载视为普通浏览器或应用内下载路径的验收。

ZIP 与只读挂载的 DMG 均通过严格嵌套验签。两个包的 Info.plist、三个可执行文件及五个图标资源一致，架构为 arm64，无 Python 运行时。应用仍使用 ad-hoc 代码签名，不构成 Developer ID 公证验收。

两个正式包中的 `CyberAudio.icns`、`MenuBarIdle.png`、`MenuBarIdle@2x.png`、`MenuBarActive.png`、`MenuBarActive@2x.png` 均与设计源文件逐字节一致。AppKit 成功读取 ICNS 的 10 个尺寸表示，以及两个菜单栏图标各自的 18／36 像素表示；菜单栏逻辑尺寸均为 18 × 18 pt，素材为黑色图形加透明通道。应用配置的 `CFBundleIconFile` 指向新 ICNS。

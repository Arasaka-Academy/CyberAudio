# CyberAudio 0.2.0（4）

- 集成 Sparkle 2.10.1 自动更新，默认每天检查并下载稳定版。
- 新增软件更新设置、应用菜单与菜单栏入口，显示版本、检查时间、下载状态和错误重试。
- 运行中确认安装并重启，主动退出时安装已下载更新；更新等待音频与已有 API 推理完成，可取消等待并恢复服务。
- ZIP 与更新清单使用 EdDSA 签名，解压前验证。模型、独立 Python 环境、Token、配置和日志保留。
- GitHub Releases 提供 DMG、完整更新 ZIP 与校验文件；稳定清单由 GitHub Pages 发布。

从旧版本需手动安装本版一次，后续可通过应用内更新。重启前请复制需要的文字并保存音频。当前 App 使用 ad-hoc 签名，尚未 Apple 公证。首次安装仍需准备模型、Python 环境和 FFmpeg。

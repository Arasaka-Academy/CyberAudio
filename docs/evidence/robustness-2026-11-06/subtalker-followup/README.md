# 独立辅助生成器温度对照

本阶段只在私有 SDK 副本中比较主生成器 0.7／辅助生成器 0.7 与主生成器 0.7／辅助生成器 0.9，正式采样默认值未修改。Qwen 参考实现和固定模型 generation_config 分别配置两者；这项结构差异本身不能证明根因或质量改善。完整原始字节在 `.context/robustness/m4-acceptance-20261106/` 保留。

## 已知失败的重复对照

[预先固定的六个样本](preliminary-plan.json)包含种子 196 的基线／候选及重复，以及种子 31 控制。两次基线均与先前原 SDK 失败的 token 和 PCM 逐字节相同，1200 token／96 秒无 EOS；两次候选均在 62 token／4.88 秒结束且字节一致。12 次实际 ASR 回读中，基线四段分别为“啊／嗯／嗯／嗯”，两次候选和控制对均保留完整输入文本。见[生成结果](preliminary-generations.json)与[回读](preliminary-asr.json)。

私有构建首次在链接输入检查误把带引号的空格路径当作字面路径而失败，尚未启动推理；修正检查后复用已完成的私有模块编译并链接，失败回执仍保留。正式 App、安装、模型和采样配置未因此替换。

## 完整固定配对

[预先固定的四文本／九音色／四种子组合](matrix-plan.json)共生成 144 个新候选，约 410 秒。全部完成，不按结果提前停下；144 个旧基线音频直接复用，没有重跑 TTS 以挑选成功结果。随后两组全部通过同一个最终签名 Helper 的实际 ASR，共 294 次请求；150.95 秒完成，正常退出、临时目录清理及生产配置／Token 保留。旧基线的新回读与此前原始文本 144／144 相同。

| 描述性指标 | 原基线 0.7／0.7 | 私有候选 0.7／0.9 |
|---|---:|---:|
| 输出数 | 144 | 144 |
| 无 EOS | 1 | 0 |
| 最长音频 | 96 秒 | 14.88 秒 |
| 规范化回读完全一致 | 124 | 126 |
| 总字母／数字编辑数 | 91 | 45 |

配对回读有 15 对编辑数减少、118 对相同、11 对增加。包括候选把“十一月”回读为“十月”、Alice 回读为 Ellis／Alex／Alec 等问题。即使总指标改善，仍不能宣布人名、日期或音质通过。完整[汇总](summary.json)、[逐对结果](paired-results.json)和[全部 ASR 响应](paired-asr.json)保留，不隐藏变差样本。

这不是随机总体失败率、正式 CER／WER 或人耳结果：种子包含先前挑出的失败样本，回读混合 TTS 与 ASR 误差，规范化没有数字语义等价和实体标注。没有将候选提升为默认值，也没有以这次结果替代已失败的 M4 严格两小时门槛。

本阶段使用语言路由修复前的 SDK；尤其英语 eric／dylan 的结果不能替代后续版本的对应回归。模型混合语言、物理麦克风／桌面、公网完整下载及 Developer ID 分发验收仍独立保留。

[复核回执](verification.json)验证 294 组实际 PCM／token 摘要与 294 个 ASR WAV，音频、权重和凭据不纳入本目录。采集源码副本用于审阅，不直接在 docs 中运行。完整编译参数保留在私有构建回执，由本目录 builds.json 的 SHA 对应。

## 固定协议

[协议](protocol.json)在创建转发和网络请求前冻结。目标是验证上轮断线后的传输是否足够持续，不将单次小 Range 成功直接作为完整下载资格。

复用不变的本机现有代理，通过一个专用 SSH master 同时承载命令和反向转发，M4 仅监听 `127.0.0.1:17891`。`IPQoS=none` 只作用于本次 SSH 命令；没有改变系统代理、DNS、TLS 或生产服务设置，也没有把该命令选择当作先前故障的已证明原因。

计划在相对 0／45／90／135 秒发起四个相邻 8MiB 请求，起点分别为 `184549376 + index × 8388608`。每项使用原固定 Hugging Face revision，URLSession 标准证书校验和 45 秒资源期限；对照目标机现有完整模型的对应字节 SHA。先核验该参考模型的完整固定摘要，以及既有 14 个最终文件的固定大小／SHA。

完整续传的前置条件为四项全部通过，且活动传输速度足以把剩余字节预计在 2,400 秒内完成，为原 3,600 秒有界续传预算留出 1.5 倍余量。出现任何失败即停；本协议不重试、不执行完整下载、不写模型目录，也不加载推理模型。

## 来源与验收边界

[RangeProbe.swift](RangeProbe.swift)为实际使用的原生程序；[remote.py](remote.py)为远程采集程序的审阅副本，依赖私有验证目录。启动器先排他创建本次目录及 Swift 文件，再把其中的 `ROOT.mkdir(...)` 改成存在性断言；执行版本摘要单独保留在外层回执。其他源代码体保持一致，没有改写原模型或下载器。

[来源清单](source-manifest.json)与[私有摘要](private-artifacts.json)记录原始文件及裁剪方式，[SHA256SUMS.txt](SHA256SUMS.txt)覆盖公开文件。内部主机名、生产实例／配置／Token 摘要、完整文件树和日志保持私有。

这次检查不能证明完整 Hugging Face 下载、SOCKS5、大文件长期稳定或新目录模型加载成功，也不涉及 FFmpeg 从零安装。下一次完整续传仍须新的持续传输或明显改变的有效路径证据；已有断点保留。短句 TTS、自然混说、原严格 M4 两小时、现场与分发验收继续保持未完成。

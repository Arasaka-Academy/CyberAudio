## 预先固定的方法

全部十二个旧输入保留：八个中英双顺序／clean／20dB 噪声的等 RMS 拼接，以及四个单语控制。来源为原固定 FLEURS 人类录音，受控拼接与自然混说分别处理；来源、许可和既有质量边界见[前序证据](../quality-boundaries/README.md)。

规则在查看新 ASR 输出前写入 `plan.json`：20ms 能量窗、10ms 步长、最长 18 秒；在第 8–18 秒区间选择最长的至少 200ms 低能量段中点。低能量门槛取 -42dBFS 与全文件 95 分位 RMS 的 0.1 倍中的较大值。没有合格段时使用靠近最大长度的最低能量窗。切点不使用转写、语种或已知拼接边界，不丢弃或重叠任何音频；只用空格连接各段结果，不去重或重写。

执行 **28 次实际 HTTP ASR**：十二个新的一次性原样基线，以及八个混合输入的十六个分段。四个单语输入均短于 18 秒，候选复用相同原样请求，不另算推理。最终 Service SHA `46083a4f7ba269b7f28377bd9532ede44ac0a812a55a55d1e1f0a9bd225cf86d`，隔离端口 18894。外层 exit 0，33.69 秒；十二个新基线文本均逐字复现前序最终 App 输出。

## 结果与评分限制

预定诊断单位为 NFKC／casefold 后的每个汉字及其他连续字母数字词，使用 Levenshtein 编辑距离；**不做数字语义归一化**，不是正式 CER／WER。原参考中的括号姓名也未与实际发音逐词对齐，因此绝对分数不能代表内容正确率。

包含四个复用的单语控制后，十二个输入总编辑数为 **154 → 92**；四个条件减少、两个增加、六个不变。八个分段混合文本全部有汉字和拉丁字母，之前仅输出英文的条件恢复了中文文本，但字符／脚本存在不等于内容完整或准确。

两个编辑数增加的条件必须按原条件保留：

- 英文比例在前的加噪条件，从 Arabic 数字改为英文数字词和中文数字写法，例如 `15` → `十五`、`2011` → `二零一一`、`3 to 2` → `three to two`；该变化明显影响原始编辑数，不能据此断言语义变差。
- 声明中文在前的加噪条件，英文 `34` → `thirty-four`，参考 `METI` 的原识别 `Medi` 变为 `Meddy`。两种实体拼写均未命中参考，当前指标不能证明候选发音或实体能力更差。

因此“每个样本编辑数不得增加”的预定条件为 false，**本组试验未通过**；没有改写该结果，也没有将总分下降解释为质量验收通过。数字书写和实际内容的评价需要在新的独立数据上分开设计，不能用本组结果事后调整切点再声称通过。

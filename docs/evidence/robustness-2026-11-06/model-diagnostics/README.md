# 短句 TTS 确定性复现与混合语音诊断

这些结果继续约束正式分发：短句生成可在固定种子下退化，混合语言完整性仍未解决。所有实验在 M1 独立目录完成；正式 App、Helper、模型参数和原有验收条件均未修改。

采集源码的原始工作目录为 `.context/robustness/m4-acceptance-20261106/`；本目录副本用于审阅与溯源，不直接在 docs 中运行。模型权重及音频保留在私有工作区。

## 确定性复现

[固定种子结果](seeded-results.json) 使用原始受管理 SDK 入口、`ono_anna`、Chinese、temperature 0.7、top-k 50、top-p 1、repetition penalty 1.05、最多 1200 token，输入“持续验证语音服务的稳定性和恢复能力。”。依次测试种子 0–196；196 是此次顺序扫描遇到的第一个无 EOS 样本。之后重复 196，再用种子 0 检查同模型恢复。总计 199 次生成、606.15 秒；运行器正常退出，生产实例、配置和 Token 保留，见 [运行回执](seeded-runner.json)。

种子 196 两次均输出 1200 token、96 秒 PCM，没有 EOS；[token 记录](failure-tokens.json) 和音频 SHA 证明两次 token／音频逐字节相同。同一模型之后用种子 0 正常结束。扫描在首个失败后停止，这不是预先固定规模的质量基准，也不能用一次失败计算总体失败率。

随后用只增加 `MLXRandom.seed(196)` 的[私有服务副本](seeded-service-source.patch) 跑完整真实 HTTP 路径，模型、采样参数、HTTP 和协调器保持相同。独立端口 18880 的 PCM 请求返回 200 后产生 `IncompleteRead`，保留 4,608,000 字节，音频 SHA 与上述 SDK 失败完全相同；终态请求明确为 **failed／`generation_limit`**，见 [HTTP 记录](seeded-http.json) 和[私有构建摘要](seeded-service-build.json)。同一实例随后 Serena WAV 成功，更新暂停／恢复、临时文件清理、EOF 正常退出及生产配置／Token 保留通过。

这次确认了可复现失败在实际 HTTP 服务中的表现，未把部分 PCM 当作完整成功；它不能补写首次 M4 或早期未保存请求码的探针终态。私有服务副本使用原始 SDK 对象，正式服务源码和 App 均未替换。

## EOS 与采样检查

只在私有目录编译 SDK 诊断副本，加入采样前后观察及可传入的温度；固定模型、top-k、top-p、惩罚和 token 上限保持相同。原 SDK 源码、对象文件和正式 Helper 的 SHA 在收尾复核一致，见 [构建摘要](build.json) 和 [诊断运行回执](traced-runner.json)。采集源码同目录保留。

[采样汇总](sampler-summary.json) 和 [生成结果](traced-results.json) 显示：无观察器和启用观察器的私有副本都与原种子 196 的 token／PCM 完全相同。1200 步中 EOS 均未被 top-k 等过滤屏蔽，其过滤前后 logit 完全一致；该路径 EOS 概率中位数约 8.98×10⁻⁶，最大约 4.15×10⁻⁴。因此不能把这次退化归因为“EOS 被 top-k 永久剔除”；修改其他采样条件会改变整条生成路径，不能据单个种子宣布修复。

## 混合语言的强制语言对照

相同的八个统一 RMS／顺序拼接输入分别使用 auto、zh、en，共 24 次请求。加上十个 TTS 分段回读，此次实际 Helper 共完成 34 次 ASR；另一次三样本回读独立完成。两次均退出 0、没有遗留请求目录，生产实例及配置／Token 保留。输入是受控拼接或合成语音，未计为自然混说、物理麦克风或人耳验收。

- 桥梁中文在前、比例英文在后：auto／en 只输出英文；zh 只输出中文。强制中文改变了被保留的一段，没有恢复全部内容。
- 两组英文在前的 clean 输入：auto／en 把中文段翻译成英文；zh 在这些输入上保留两种原语言。
- 此前已保留两段的条件大多继续保留两种语言；部分数字书写和标点随语言设置变化。

因此固定选择某一种语言不能解决全部拼接问题。需要面向自然混说和完整性进一步评估模型、提示或分段策略，并继续保留固定 100 条真人语料及既有接口／生命周期回归。来源归属沿用 [FLEURS 语料说明](../quality-boundaries/README.md)，模型为已固定的本地 Qwen 权重；未下载或更换模型。

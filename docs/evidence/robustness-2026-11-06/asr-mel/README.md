## 已确认的数值贡献

- 原生窗口以 Swift Float 计算，参考以 NumPy float64 计算后使用；转换成相同 float32 后，400 个窗口值仍有 **302 个不同**，最大绝对差 `3.5762786865234375e-07`。
- 原生 Slaney 滤波器以 Float 计算；参考 float64 滤波器转换成相同 float32 后，201×128 中有 **391 个值不同**，最大绝对差 `1.7881393432617188e-07`。
- 参考将采样和窗口提升为 float64 后相乘／FFT，再把 FFT 存为 complex64；原生执行 float32 加窗和 MLX FFT。即使使用相同窗口值，两条路径的频谱仍不同。本对照未进一步分离加窗乘法舍入与 FFT 算法／后端贡献，不能只归因于 FFT。
- 相同复数频谱的功率计算、相同功率／滤波器的投影，以及相同 Mel power 的 log／归一化也有精度差异。参考采用 float64 运算并在 log 后转 float32，原生主要为 float32。这些是不同数值流程，不是已判定的某个 GPU 数学模式错误。
